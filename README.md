# ensemble-methods

Ensemble-learning examples covering bagging, random forest, boosting, and heterogeneous voting.

## Files

- `BaggingClassification_BreastCancer.py`
- `BaggingRegression_CaliforniaHousing.py`
- `Bagging_RandomForest_BreastCancer.py`
- `BoostingClassification_BreastCancer.py`
- `BoostingRegression_CaliforniaHousing.py`
- `Heterogeneous_Indiviual.py`
- `Heterogeneous_Voting_Hard.py`
- `Heterogeneous_Voting_Soft.py`

## Usage

Run the scripts with pandas and scikit-learn installed. The examples use breast-cancer and California-housing datasets.
