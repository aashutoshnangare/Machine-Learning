# customer-segmentation-case-study

Mall Customers K-Means workflow covering loading, feature selection, scaling, elbow analysis, and training.

## Files

- `Mall_Customers.csv`
- `Mall_Customer_Kmean_Load_1.py`
- `Mall_Customer_Kmean_Selectfeatures_2.py`
- `Mall_Customer_Kmean_Scale_3.py`
- `Mall_Customer_Kmean_Elbow_4.py`
- `Mall_Customer_Kmean_Train_5.py`

## Usage

Run the scripts from the repository root with pandas, matplotlib, and scikit-learn installed.
